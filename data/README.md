# data/

This directory is gitignored on purpose. It holds, locally only:

- Preprocessed Human3.6M data (never the raw dataset committed here — its license prohibits redistribution)
- Camera calibration captures (checkerboard/ChArUco frames, intrinsic/extrinsic results)
- Live capture recordings of the team (generalization test set, never training data)
- Trained model checkpoints

Nothing under this directory should ever be pushed to the public repo.
